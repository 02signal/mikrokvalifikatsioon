Sora + Atkinson Hyperlegible

Motiiv

Tõusvad kriipsud = „sa liigud edasi"

Logo kolm tõusvat kriipsu korduvad struktuuris: sobivuse ribad „tõusevad", edasi-nooled nupis, aktsendid sektsioonides. See on visuaalne lubadus iga persoona motivatsioonile - taseme tõus.

Ribad täituvad laadimisel (liikumine), kald 13° kordab märki.
